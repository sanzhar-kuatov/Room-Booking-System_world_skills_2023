Это веб-приложение

Запуск сайта:
1. Открыть XAMPP запустить Apache, MySQL.
2. Заходим в PHPMyAdmin, туда импортируем мою базу данных (web_app.sql)
3. Папка самой программы(WebApplication) сохраняем в папке htdocs (эта папка находится в папке самого xampp)

Открыть приложение можно перейдя по ссылке http://localhost/WebApplication/
