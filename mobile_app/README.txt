Мобильное приложение

Для запуска приложения
1. Открыть XAMPP
2. Запустить Apache, MySQL
3. Открываем phpmyadmin
4. Импортируем базу данных(project.sql)
5. Открываем командную строку
6. С помощью команды cd, находим папку pyqt5
7. Запускаем файл с помощью команды python new.py



Примечание:
Если вы сделали то что было описано в веб-приложение, тогда можно сразу перейти на пункт 5
