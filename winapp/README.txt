Десктопные приложение

Для начало работы:
1. Вытащить из архива файл Trial1
2. Открываем Visual Studio
3. В Visual Studio, нажимаем открыть репозиторий, и там открываем папку Trial1

Если не получилось попробовать открыть файл Trial1.sln в папке Trial1

Для запуска программы надо нажать на зеленая стрелка запуска сверху экрана



Примечание:
В Visual Studio нужно скачать технология .NET, работа с серверами базы данных.
Способ который был упомянут выше для открытия программа не точен, это предположение.
